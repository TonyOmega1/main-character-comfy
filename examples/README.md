# Example outputs

- `reference_motion.md` explains how to make reference moves without third-party footage (generated or self-filmed).
- `community_format_example.json` is a template for a community meme format (copy it into `main_character_comfy/formats/community/`).
- `avatar_3d_flux2_klein.jpg` is a fictional 3D-animated character generated with FLUX.2 [klein] 4B on the reference RTX 5080. It's the avatar stage output.

Final example memes (4 formats, a pack, and a Swap Me In clip) plus the talking-avatar Shorts are rendered on the reference PC using only invented, generated characters and Chatterbox's built-in voice (no real-person likenesses). They get added here before submission, as `meme_*.mp4`, `swap_*.mp4`, `talk_*.mp4`, `duet_*.mp4`, `sing_*.mp4`, and `longform_60s.mp4`. To keep the repo small, larger files are linked from the release page.
